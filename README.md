## Overview

Mator Smash analyzes all active Bethesda game plugins, detects record conflicts, and generates a smashed patch that merges the winning values from each mod into a single compatibility plugin.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Mator Smash** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Conflict Analysis** | Scans all active plugins and reports per-record override conflicts |
| **Smash Profiles** | Save custom smash-target settings per mod for repeatable patches |
| **Exclusion Rules** | Flag specific records or mods to skip during smash generation |
| **Quick Rebuild** | Regenerate the smashed patch in seconds after a mod list change |
